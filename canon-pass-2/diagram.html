Архитектура Archie

Интерактивная карта автономного напарника: голосовой тракт с barge-in, Z-Sense, трёхуровневая память и проактивное ядро. Тяните диаграмму, крутите колесо для зума, ищите узлы, кликайте для карточки или проигрывайте сценарии.

drag — панорама · колесо — зум · клик по узлу — карточка · Esc — сброс

Легенда

  • Голубой — UI-слой: орб и дашборд на Tauri/React
  • Синий — gRPC-шина между фронтом и движком
  • Фиолетовый — Engine-ядро: LLM-каскад, Z-Sense, проактивность
  • Розовый — аудио-тракт: VAD → STT → TTS (голос ruslan)
  • Изумрудный — трёхуровневая память: буфер → эпизоды → профиль
  • Серый — внешний мир: облако (opt-in), ОС, экран
  • Пунктирные рёбра — фоновые/ночные процессы и опциональные облачные вызовы
  • Сценарий «Голосовой запрос» подсвечивает путь реплики по всей цепочке, включая barge-in (SYS_TTS_STOP)

Граница приватности. Archie — гибридный edge+cloud ассистент, не fully-local. Сырые кадры экрана и аудио предназначены оставаться локально; при opt-in cloud boundary допускается только санированный текстовый контекст. Текущий санитайзер — базовый scaffold, поэтому это намерение требует проверенных egress-тестов, а не является безусловной гарантией. Listening, screen context, cloud processing и telemetry — независимые consent-границы; telemetry в Phase 1 не реализована.
